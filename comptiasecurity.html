Complete Training Modules & Curriculum

Domain 1: General Security Concepts

Security controls, CIA triad, change management, basic cryptography, and cryptographic solutions.

Domain 2: Threats, Vulnerabilities & Mitigations

Threat actors, attack vectors, malware types, vulnerability scanning concepts, and indicator of compromise identification.

Domain 3: Security Architecture

Zero trust framework, cloud security models, secure network architecture, virtualization, and resilient enterprise design.

Domain 4: Security Operations

Monitoring tools, endpoint security, log review, basic incident response life cycle, and forensics basics.

Domain 5: Program Management & Oversight

Risk management, compliance frameworks, privacy, audits, and physical security controls.
