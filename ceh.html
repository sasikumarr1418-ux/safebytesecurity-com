Complete Training Modules & Curriculum

Module 1: Introduction to Ethical Hacking

Information security overview, cyber threats, attack vectors, and ethics.

Module 2: Footprinting and Reconnaissance

OSINT techniques, website footprinting, email tracking, and DNS enumeration.

Module 3: Scanning Networks

Network scanning tools (Nmap), ping sweeps, port scanning, and IDS/Firewall evasion.

Module 4: Enumeration & Vulnerability Analysis

NetBIOS, SNMP, LDAP enumeration, and automated vulnerability scanning tools.

Module 5: System Hacking & Malware Threats

Password cracking, privilege escalation, Trojans, spyware, ransomware analysis, and rootkits.

Module 6: Web Applications, Cloud & IoT

OWASP Top 10 vulnerabilities (SQL Injection, XSS), web server attacks, and cloud security misconfigurations.
