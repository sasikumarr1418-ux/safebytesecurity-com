Complete Training Modules & Curriculum

Module 1: SOC Operations & Architecture

Security Operations Center setup, tier-1/tier-2 analyst roles, and alert monitoring workflows.

Module 2: Incident Handling Frameworks (NIST & SANS)

Preparation, identification, containment, eradication, recovery, and post-incident lessons learned.

Module 3: SIEM Log Analysis & Threat Hunting

Splunk / ELK stack querying, parsing security logs, and identifying brute-force attempts.

Module 4: Network Packet Triage & PCAP Analysis

Analyzing malicious traffic captures, spotting command-and-control beacons, and data exfiltration.

Module 5: Endpoint Forensics & Malware Triage

Live memory dumping, inspecting running processes, isolating infected workstations, and sandboxing.
